# w2_coaches_lofts: notes

Built from four parallel passes (part files in `parts_w2_coaches_lofts/`): gear shops (60 rows), rigging lofts and
rigger/packing courses (74), canopy/freefly/wingsuit/camera coaching (43), instructor-rating organisers and independent
AFF instructors (41). Merged and de-duplicated by website + email: 218 -> 198 rows, 144 with email, 34 countries
(USA 81, Germany 13, UK 11, France 9, Spain 9, Russia 9, Australia 7, Canada 6).
Types: rigger 75, coach_school 69, other (gear shop) 54. Confidence: high 92, medium 64, low 42.

## Sources
- Own sites and contact pages (most rows).
- Dealer lists: flysight.ca/dealers, flyfirebird.com/fb/dealers, Cypres dealer directory (medium rows for shops).
- Skytime riggers directory (skytime.app/riggers): Russian and many EU lofts; EU emails are masked there (low rows).
- Dropzone coach pages: Skydive Perris, Skydive Sebastian, Skydive Arizona, Spaceland, Paraclete XP, UK Parachuting.
- flight-1.com/dropzones; federation PDFs/pages: British Skydiving, CSPA, DFU, FFP, DFV, APF, NZ Skydiving; HLB/BWLV Fallschirmwart course PDFs.

## Completeness
- No single directory holds this scope. Best single sources: the FlySight/Firebird dealer lists (shops) and Skytime (lofts).
- Gear shops: good for US/EU; none found in NZ, Ukraine, Sweden.
- Lofts: good for US/UK/DE/AU; thin for Ukraine, Brazil, Nordics.
- Coaching: big US names covered; AU/NZ, RU/UA, LatAm and camera schools are thin. The shared search limit (200/turn) ran
  out in three passes, so Norway, Sweden, NL, CH, PL, IT, BR, UA instructor searches and UK/AU coach searches never ran.
  Estimate: around 60% of the reachable scope. A second pass on those countries would add maybe 50-80 rows.
