# Glossary: Lithuanian (lt)

Terms as used in Lithuanian skydiving training, taken first from the Lithuanian AFF course manual of the Kaunas
parachute club at Pociūnai (Kauno parašiutininkų klubas, the main Lithuanian AFF school), then from common Lithuanian
dropzone usage. Lithuanian training keeps a few words in English ("AFF", "RSL", "lock on", "hard deck",
"downplane", "line-over", "wave-off", the exit commands "Check in / Check out / Prop / Up / Down / Arch"); where it
does, the app keeps the English word and adds the Lithuanian one in brackets the first time it appears in a string.

Sources:
- Kauno parašiutininkų klubas (Pociūnai), "Pagreitinto parašiutininkų parengimo (AFF) mokymo kurso mokomoji
  medžiaga", 2017: https://skydive.lt/file/repository/kurso_medziaga.pdf (linked from https://skydive.lt/aff-programa).
  Source of: pagrindinis / atsarginis parašiutas, kupolas, kuprinė, pakaba, ištraukiamasis parašiutėlis (medūza),
  atkabinimo pagalvėlė, atsarginio parašiuto žiedas, trijų žiedų atkabinimo sistema, saugos prietaisas (CYPRES,
  Vigil), greito skleidimo sistema (tranzitas, RSL), stropai, valdymo stropai, valdymo kilpos, laisvieji galai,

Drift found and fixed:
- Exit words (key hk905t): a draft added the Pociūnai Lithuanian exit count ("Pirmyn – Atgal – Išsilenkti") to the
  examples. Removed, since nothing may be added; it is noted here instead.
- "kack2k" ("system", the theme option next to light/dark) was first rendered as a genitive ("sistemos"); fixed to
  "sistema".
- Checked on the back-translation: every emergency sequence keeps the English order (look red, grab, look silver,
  grab, pull red, pull silver; arch, altitude, pull; two tries or 5 s, then the emergency procedure). No drift found.
- Kept deliberately apart: "pagalvėlė" is used only for the red cutaway handle (Pociūnai "atkabinimo pagalvėlė"), the
  flare is always "stabdymas" (never "pagalvė", the Pociūnai bracket word), so the two cannot be confused. The
  reserve handle is "atsarginio parašiuto žiedas" (ring), the release is always "trijų žiedų sistema".
- Kept deliberately apart: "atrišk valdymo kilpas" (unstow brakes) vs "paleisk valdymo kilpas atgal į viršų" (let
  the toggles up in a flare).

Least sure (for a native instructor to check):
1. "stabdymas" for flare (some Lithuanian jumpers say "pagalvė" or keep "flare").
2. "skersinė atkarpa" for base leg (Pociūnai calls the point "pasitikrinimo taškas"; leg name not in the manual).
3. "neutrali padėtis (box)" for box position, and "imitaciniai skleidimai" for practice touches.
4. "vėduoklė" for side-by-side and keeping "downplane" in English.
5. "laukimo taškas / zona" for holding point / area (not in the Pociūnai manual).
