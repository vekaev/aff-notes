# Swedish (sv) glossary: AFF notes

Target: the words Swedish jumpers and SFF (Svenska Fallskärmsförbundet) clubs use. SFF's own training handbook
(utbildningshandbok) is not public online, so I could not quote it. Two sources were checked instead:

- **Elevens guide** (Swedish-language student manual of the Finnish Aeronautical Association, Fallskärmskommittén,
  15.2.2022): https://laskuvarjotoimikunta.ilmailuliitto.fi/elevens-guide . It is Finland-Swedish, so where Sweden
  says it differently (e.g. "styrlänkar" vs "styrhandtag") the Sweden word was chosen and the Finnish one is noted.
- SFF safety presentations to Transportstyrelsen (organisation context only, no terms):
  https://www.transportstyrelsen.se/globalassets/global/luftfart/seminarier_och_information/2022/svenska-fallskarmsforbundet-sff.pdf
- USPA SIM glossary for the English meaning: https://uspa.org/SIM/Glossary

Swedish skydivers keep many English words (flare, slider, AAD, RSL, lock on, wave-off, hard deck, downplane, line-over,
bag lock, tracking). These were kept where the sport keeps them. The spoken exit commands of the US school
("Check in", "Check out", "Prop", "Up", "Down", "Arch!") stay in English because the student hears them in English.

### Drift found and fixed
- **15f19l8**: first draft said "Bruten lårbenshals" (broken femoral neck) for "broken femur". Fixed to
  "Brutet lårben och bruten fotled".
- **1vvbt2h**: link text "the five-second rule" was written "5-sekundersregeln", which added a digit the test rejects.
  Changed to "femsekundersregeln" (same meaning).
- "Brakes stowed" vs "brakes released": Swedish "släppa bromsarna" can mean both unstow and let up. In the line-twist
  strings the order (untwist first, then unstow) is spelled out, so the meaning stays safe; flagged below.

## Least sure (for a Swedish instructor to check)
1. **kapa / kapphandtag** for cutaway / cutaway handle (Finland-Swedish uses "lösgöring").
2. **styrhandtag** for toggles (Finland-Swedish "styrlänkar"; many Swedes just say "toggles").
3. **landningsvarv** with **medvindsben / basben / final** for the pattern and its legs (Finnish manual: "landningsmönster", "grunddelen").
4. **släppa bromsarna** for "unstow the brakes" and **bromsarna låsta** for "brakes stowed".
5. **medvetenhetscirkel** for circle of awareness, and **pinnkontroll** for pin check.
