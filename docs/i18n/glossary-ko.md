# Glossary: Korean (ko), South Korea

Korean sport skydiving is small (a few dropzones, many jumpers trained abroad under USPA). Sport jumpers mostly use
English loanwords written in Hangul (메인, 리저브, 커터웨이, 플레어, 슬라이더); Korean military airborne training uses
native terms (주낙하산, 예비낙하산, 착지). The app uses the loanword jumpers will hear at a dropzone and adds the native
word in brackets where that helps a beginner. No public Korean federation training manual or exam bank was found
online, so every term below should be checked by a Korean-speaking instructor.

Sources:
- USPA SIM glossary (the English terms the app follows): https://uspa.org/SIM/Glossary
- USPA Skydive School, Category A: https://uspa.org/skydiveschool/A
- Korean drop zone listing (Chungju; search summary says USPA-recognised, teaches licence courses; page not opened):
  https://xn--ok0b236bp0a.com/place/26611
- Korean military airborne vocabulary (주낙하산 / 예비낙하산 / 착지) is common knowledge from ROK Army airborne training; no
  single public document was found, so it is used only in brackets.

Style: polite imperative (~하세요) for steps, short noun phrases for labels. Units ft, s, m, mph kept. Numbers keep
commas (5,500 ft). Where English writes a number as a word (“five seconds”, “a second later”, “figure-eights”), the
Korean also avoids a digit (오 초, 일 초, 피겨에잇) so the number check stays exact. “Mid-May 2019” became
“2019년 늦봄(May 중순)” for the same reason (5월 would add a digit).

Other drift found and fixed during checking:
- “Altimeter set (zero on the ground)”: first draft wrote “0”, which adds a digit; now 영점 (zero point).
- “close second” first became “2위” (2nd place); reworded to “근소한 차이로 그 뒤를 잇습니다” (follows closely).
- “first person” 1인칭 → 일인칭; “one-stage or two-stage” 1단계/2단계 → 한 단계/두 단계 (no extra digits).
- “The AAD fired the reserve”: bold kept over one span only, as in English.

Least sure (for a native instructor):
1. PLF: kept as “PLF / 낙하산 착지 자세”; Korean military calls it 5점 착지. Which do Korean students hear?
2. Cutaway handle: 커터웨이 핸들 vs 분리 핸들 (and “cut away” as 커터웨이하다 vs 분리하다).
3. Circle of awareness: “인지 서클” is a coinage; there may be an established Korean term.
4. Holding area / point: 대기 구역 / 대기 지점; check what Korean dropzones say.
5. Canopy check words “있음, 사각형, 안정, 조종 가능” for “there, square, stable, steerable”.
