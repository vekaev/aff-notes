# Glossary: Thai (th), Thailand

Terms for Thai-speaking AFF students. Thai skydivers (Thai Sky Adventures, Skydive Thailand at Pattaya / Chonburi) are
taught mostly in English by international staff, so many words stay English in speech: AFF, flare (แฟลร์), slider
(สไลเดอร์), lock on (ล็อกออน), hard deck, RSL, AAD, pin check, bag lock, biplane / side by side / downplane. The app
uses the Thai word where a clear, common one exists (ร่มหลัก, ร่มสำรอง, ร่มนำ, มาตรวัดความสูง, ขั้นตอนฉุกเฉิน) and
keeps the English word, sometimes with the Thai one in brackets once, where Thai jumpers say it in English. Thai
military parachuting (พลร่ม, หลักสูตรส่งทางอากาศ; free fall = ดิ่งพสุธา) uses ร่มหลัก / ร่มสำรอง / ร่มนำ for main /
reserve / pilot chute. Western digits, comma thousands (5,500 ft), units kept as ft / s / m / mph.
