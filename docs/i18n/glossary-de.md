# Glossary: German (de), Germany / Austria / Switzerland

Terms as used in German-speaking skydiving training (DFV / DAeC, ÖAeC, SHV-FSV) and at drop zones. Where German
jumpers keep the English word (Flare, Slider, Lock-on, Hard Deck, Downplane, Pin-Check, AAD, RSL), the app keeps it.

Sources:
- DAeC/DFV Ausbildungshandbuch (AHB) Teil I, V9: https://www.daec.de/media/files/2022/Luftsportgeraete_Buero/Fallschirm/AHB_Teil_I_Version_9_.pdf
- DFV Lernfragen Technik (2022): https://www.dfv.aero/downloads/Lernfragen-TECHNIK_16.03.2022.pdf
- DFV Safety Day poster 2008 ("Trennkissen", "Reservegriff", "Landenotfälle", "Leinenverdrehungen"): https://www.dfv.aero/downloads/Top-Thema_2008_Poster_2_Safety_Day.pdf
- Student rig manual in German on paraorg.dfv.aero (Gurtzeug terms; not opened, listed by search): https://paraorg.dfv.aero/uploads/bhb_style_student.pdf
- Landeeinteilung legs (Gegenanflug / Queranflug / Endanflug), DHV teaching material: https://service.dhv.de/dbfiles/gl/gutachter/Vorlagen_Dateien/DHV-Info-Berichte/Landeinteilung_und_Landung.pdf

Choices worth knowing:
- The AI prompt (`108z8a3`) ends "Antworte auf Deutsch." (English said "Reply in English."): localised on purpose so the
  student's AI replies in German.
- Language name `English` kept as-is (native name, like the language menu).
- Feet values kept with `ft`, German thousands dot (5.500 ft); "6 in (15 cm)" kept.
